# Kozy Fix

Aplicacao para personalizar e otimizar configuracoes de rato, teclado, jogos e ecrã no Windows.

## Transferir

[Descarregar a versao mais recente para Windows](https://github.com/artkozy63-lab/kozy-fix/releases/latest)

Na pagina da release, descarregue o ficheiro **Kozy.Fix.Setup.1.7.3.exe**.

## Instalar

1. Execute o instalador descarregado.
2. O Windows podera pedir permissao de administrador para instalar e utilizar algumas funcionalidades.
3. Se o Windows apresentar um aviso de protecao, escolha executar apenas se confiar no ficheiro obtido nesta pagina oficial.

> Nota: o instalador atual nao possui assinatura digital, por isso o Windows SmartScreen pode apresentar um aviso.

## Funcionalidades

- Configuracoes para dispositivos e perifericos.
- Ferramentas e ajustes para jogos.
- Opcoes de personalizacao da interface e do perfil.
